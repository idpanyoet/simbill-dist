TUJUAN
------
Bikin `simbill-dist` sekali-install langsung jalan: SimBill binary +
FreeRADIUS + 3 service pendamping (WA Mandiri, WAHA, ACS Lite) kepasang
otomatis. Semua add-on: guarded (skip kalau resource kurang), NON-FATAL
(gagal add-on tidak menggagalkan SimBill), idempoten (aman diulang).

Asumsi: MariaDB + tabel SimBill (schema) sudah ada. FreeRADIUS SEKARANG
ikut dipasang otomatis (tidak diasumsikan ada lagi).

CARA DEPLOY (TANGAN nyOet — jangan otomatis)
--------------------------------------------
1) Push 6 script ke repo simbill-dist branch main:
     cd <clone simbill-dist>
     cp install.sh update.sh setup-freeradius.sh setup-wa-gateway.sh \
        setup-waha.sh setup-acslite.sh .
     git add -A && git commit -m "turnkey: FreeRADIUS + WA Mandiri + WAHA + ACS Lite auto-install"
     git push

2) Upload acslite.tar.gz sbg asset ke Release TERBARU (yg dipakai install.sh):
     gh release upload <tag-terbaru> release-assets/acslite.tar.gz --clobber
   (atau lewat web GitHub: Releases > edit > drag acslite.tar.gz)

3) (opsional) Kalau mau versi baru, bump VERSION + rilis seperti biasa.

BELUM DIUJI DI VPS BERSIH (WAJIB sebelum rollout massal)
--------------------------------------------------------
  - install.sh utuh dari VPS KOSONG (semua add-on sekaligus). Di dev tiap
    komponen diuji terpisah & sudah jalan; tapi run installer end-to-end
    dari nol belum. Uji 1 VPS percobaan dulu.
  - ACS Lite: setup-acslite.sh SEKARANG bikin DB+user 'goacs' TERPISAH
      (sudah dicocokkan dgn /opt/acs/.env dev):
        DB_DSN=goacs:<pass>@tcp(127.0.0.1:3306)/goacs?parseTime=true
      GoACS auto-migrate tabel (devices, tasks) sendiri saat start — tak perlu
      import schema. Installer butuh user admin MySQL (DB_USER SimBill) yang
      punya privilege CREATE DATABASE + CREATE USER + GRANT; kalau tidak, script
      cetak SQL manual buat dijalankan sbg root MySQL. CEK di VPS percobaan:
      systemctl is-active acslite + ss -ltnp | grep 7547 + SHOW TABLES FROM goacs.
